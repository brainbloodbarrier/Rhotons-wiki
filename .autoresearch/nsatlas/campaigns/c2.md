# C2 — Augment Campaign (nsatlas)

## Theme

Augment existing nsatlas vault pages with technique-specific detail extracted
from `/Users/fax/code/dev-nsatlas/nsatlas/pdfs/english/*/*.pdf`. Additive only.
One page per iteration. No creation of new derivative synthesis pages in C2 —
those belong to a separate synthesis campaign.

## Measurable target

For every source subdir, at least ONE vault page must meet all of:

- Has a matching entry in `nsatlas-wiki/vault/.manifest.json` (source PDF anchor).
- Frontmatter contains ≥1 typed breadcrumb relation (`parent|child|branch-of|
  branches|innervates|innervated-by|traverses|traversed-by|approach-to|
  approached-via|drains-to|drained-by`).
- Body contains ≥5 distinct `[[wikilink]]` targets (excluding embeds).
- Frontmatter `sources:` entry cites chapter/section, not just
  "NSAtlas — Cohen-Gadol".

## Stop condition

Stop C2 when any of the following:

1. All in-scope subdirs meet target (success).
2. 3 consecutive iterations with Δscore_v1 < 3 AND zero new breadcrumbs added
   (signal of drift to padding).
3. Iter budget (below) exhausted.
4. Quality gate hard-fails (`guard --quality --strict` returns non-zero).

## Iter budget

stop and re-brief: evaluate whether remaining subdirs need source material
pulled, or whether target is unreachable with current corpus.
