# Skull Base Foramina

The skull base contains numerous foramina through which cranial nerves, arteries, and veins pass between the intracranial cavity and extracranial structures. Knowledge of foraminal contents is essential for approach planning and intraoperative orientation. This page provides a complete reference map organized by cranial fossa.

|---|---|---|---|
| **Cribriform plate foramina** | Ethmoid | [[olfactory-nerve|CN I]] (olfactory nerve filaments) | [[cranial-base]] |
| **Anterior ethmoidal foramen** | Frontoethmoidal suture | Anterior ethmoidal artery ([[ophthalmic-artery]]), anterior ethmoidal nerve | [[paranasal-sinuses]] |
| **Posterior ethmoidal foramen** | Frontoethmoidal suture | [[ethmoidal-arteries|Posterior ethmoidal artery]] ([[ophthalmic-artery]]), posterior ethmoidal nerve | [[paranasal-sinuses]] |

## Relations

- [[cranial-base]] is the bony framework containing all foramina
- [[sphenoid-bone]] contains the most middle fossa foramina (optic canal, SOF, rotundum, ovale, spinosum)
- [[temporal-bone]] contains IAC, jugular foramen (partial), hiatus for petrosal nerves
- Occipital bone contains [[foramen-magnum]], hypoglossal canal, jugular foramen (partial)
- All cranial nerves (see [[cranial-nerves-overview]]) exit through specific foramina
- [[anterior-circulation]] (ICA, [[ophthalmic-artery]]) enters via the carotid canal and optic canal
- [[posterior-circulation]] ([[vertebral-artery]]) enters via the [[foramen-magnum]]
- [[dural-venous-sinuses]] exit via the jugular foramen (sigmoid → IJV)
- [[cavernous-sinus]] is the intracranial venous hub receiving and distributing through multiple foramina
- See [[surgical-approaches-overview]] for approach-foraminal correlation
