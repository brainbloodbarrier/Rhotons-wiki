# Neuroradiology — Imaging Modalities Overview

*Source: NSAtlas, Cohen-Gadol (contributor: Aaron Kamer, MD et al.)*

The neurosurgeon's minimum working knowledge. Imaging is the single most powerful noninvasive tool for diagnosis and operative planning. **Regular consultation with an experienced neuroradiologist remains non-negotiable** — but the surgeon must read independently for decision-making.

**Critical rule**: **imaging > 3 months old must be repeated** before operative planning. Lesional change in that window changes differential and plan.

## The First Question — Intra-axial vs Extra-axial

| Intra-axial (within parenchyma) | Extra-axial (outside parenchyma) |
|---------------------------------|----------------------------------|
| Acute infarction | Meningioma |
| Abscess | Schwannoma |
| Astrocytoma, GBM | Chordoma |
| Metastasis (most) | Epidural/subdural hemorrhage |
| Primary CNS lymphoma | Metastasis (dural-based) |

Not mutually exclusive — some tumors cross both.

## CT — The Emergency Workhorse

**"Plain CT" without contrast is almost always the first study** for suspected intracranial pathology. Fast and cheap.

### Critical CT pathologies to read fluently

- **Hydrocephalus**
- **Foreign bodies, skull fractures**
- **Epidural / subdural hematoma**
- **Subarachnoid hemorrhage** → see [[imaging-sah-and-aneurysm]]
- **Intraparenchymal hemorrhage**
- **Herniation** — subfalcine, uncal, tonsillar

### Density terminology

- **Hyperdense / hyperattenuated** = bright → acute blood, calcification, bone, contrast, high-cellularity tumor (lymphoma, meduloblastoma)
- **Hypodense / hypoattenuated** = dark → edema, infarct, most tumors, air, fat

### CTA / CTV

- Arterial mapping: aneurysms, AVMs, large-vessel occlusion, dissection
- Venous mapping: sinus thrombosis, vein-of-Labbé mapping before petrosal (see [[cranial-base-preoperative-considerations]])

### CT Perfusion

- Three supratentorial vascular territories
- **Acetazolamide challenge** demonstrates **steal phenomenon** in moyamoya / chronic stenosis

## MRI Sequences — The Working Taxonomy

| Sequence | Clinical utility |
|----------|------------------|
| **T1** | Precontrast hyperintensity = lipid, subacute blood (day 2–28), melanin, calcium, proteinaceous fluid. Postcontrast enhancement = BBB breakdown / vascularity |
| **T2 / FLAIR** | Hyperintensity = vasogenic edema, gliosis. Evaluates SAH, meningitis, leptomeningeal carcinomatosis, stroke, tumor, demyelination |
| **T2\* (GRE / SWI)** | Sensitive to susceptibility — **small hemorrhage, calcium, cavernous malformation**, superficial siderosis (chronic SAH, hemorrhagic aneurysm) |
| **DWI** | Restricted diffusion = hypercellular tumor (lymphoma, medulloblastoma), **abscess** (ring enhancement + internal restriction + T2-dark rim), **cytotoxic edema** (acute infarct core) |
| **MR Perfusion (rCBV)** | Tumor grading (high-grade glioma ↑rCBV), penumbra assessment in stroke (DWI/PWI mismatch), radiation necrosis (↓rCBV) |
| **CT Perfusion** | Stroke penumbra, steal phenomenon |
| **DTI / tractography** | White matter tract preservation — corticospinal, arcuate fasciculus, optic radiations before resection |
| **fMRI** | Motor, language (Broca/Wernicke), memory localization for preop planning |
| **MRS** | Choline (Cho) / NAA / Creatine (Cr). **High-grade tumor**: ↑ Cho/NAA, ↑ Cho/Cr. **Radiation necrosis**: ↑ lactate, ↓ other metabolites. See [[radiation-necrosis]] |

### T1 hyperintensity differential (classic)

- Lipid (lipoma of corpus callosum)
- Subacute blood (days 2–28)
- Melanin (melanoma metastasis — multiple T1-bright lesions)
- Proteinaceous fluid (Rathke cleft cyst)
- Calcification (occasional, usually dense)

### Ring-enhancing lesion differential

Use DWI + T2 + clinical context:
- **Abscess** — restricted diffusion center, T2-dark rim
- **Metastasis** — no restriction, more edema than GBM often
- **GBM** — thick irregular rim, central necrosis, often no restriction centrally
- **Resolving hematoma**
- **Toxoplasmosis, tuberculoma** (immunosuppressed)
- **Radiation necrosis** (post-treatment, ↑ lactate on MRS, ↓ rCBV)
- **Demyelination** — open-ring enhancement, tumefactive MS

## Catheter (DSA) Angiography

Still the gold standard for:
- Aneurysm morphology + neck + branch relationships
- **AVM architecture** — feeders, nidus, drainers, flow-related aneurysms
- **Dural AV fistula** classification (Cognard, Borden)
- **Vasospasm** surveillance post-SAH
- **Balloon test occlusion (BTO)** — before therapeutic ICA sacrifice
- **Preoperative embolization** — meningioma, glomus, JNA, AVM

## Advanced Techniques at a Glance

- **DTI**: tract-averaged fiber directionality; disrupted tracts = tumor infiltration; displaced tracts = mass effect with preserved fibers
- **fMRI**: BOLD signal — reserved for eloquent-cortex lesions. Task paradigms (motor, language, memory)
- **MRS**: voxel chemistry; distinguishes tumor progression from radiation necrosis (the **Cho/NAA + lactate pattern**)
- **SWI**: superior to GRE for microbleeds, cavernomas, siderosis
- **Arterial spin labeling (ASL)**: gadolinium-free perfusion

## Imaging Recommendations by Presentation

| Presentation | First line |
|--------------|------------|
| Acute neurologic change, trauma | **Non-contrast CT** |
| Tumor workup | **MRI with and without contrast + DWI** |
| Vascular evaluation | **CTA + MRA**, then **DSA** if intervention contemplated |
| SAH workup | CT → LP if negative → **CTA / DSA** (see [[imaging-sah-and-aneurysm]]) |
| Stroke, acute | **CT + CTA + perfusion** (thrombectomy windows) |
| Preop eloquent-cortex lesion | **MRI + fMRI + DTI** |
| Posttreatment recurrence vs necrosis | **MRI + MRS + perfusion** |
| Preop skull base | MRI + CT bone + MRV + CTA (see [[cranial-base-preoperative-considerations]]) |

## Pearls and Pitfalls

- **Clinical acuity + age narrow the differential** more than any single imaging finding
- **Intra- vs extra-axial** is the first call — determines the entire subsequent DDx tree
- **Imaging > 3 months is stale** — repeat before operative planning
- **DWI is the abscess-maker** — restricted diffusion inside a ring-enhancing lesion raises pus over tumor
- **MRS + perfusion rescue ambiguous follow-up scans** — radiation necrosis vs recurrence
- **Always scrutinize venous phase** before skull-base, parasagittal, or petrosal cases
- **T1 hyperintensity without contrast** is a five-item DDx — memorize it
- **SWI for the elusive cavernous malformation** and chronic SAH siderosis
